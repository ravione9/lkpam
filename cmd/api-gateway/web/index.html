How policy assignment works

  1. Admin sets your role on the Users tab (e.g. netops, sysadmin).
  2. Or admin adds you to a Group that grants a role (e.g. "Network Ops" → netops).
  3. Admin creates Policies bound to that role + target kind + tier.
  4. If policy requires approval, submit an access request and wait for a different admin to approve.
